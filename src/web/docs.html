GET /api/create
🚀 Buka di Browser

Membuat alamat email acak baru secara instan. Cukup buka link di browser atau panggil via GET. Otomatis terhubung dan siap menerima email/OTP.

CONTOH REQUEST URL:
https://rzmail.my.id/api/create
CONTOH RESPON JSON (201 CREATED): 
{
  "success": true,
  "address": "tekukurgembira47@zallpyx.xyz",
  "isLocked": false,
  "isOwner": true,
  "created": true
}
GET /api/custom/:address
🚀 Buka di Browser

Membuat custom email dengan username dan domain yang kamu inginkan secara bebas! Bisa dipanggil langsung lewat URL path (misal /api/custom/namakamu@zallpyx.xyz) atau lewat query parameter ?name=...&domain=....

PARAMETER QUERY OPSIONAL:
Parameter Contoh Nilai Fungsi
name botku Username awalan email (jika panggil /api/custom tanpa path)
domain zallpyx.xyz Pilih salah satu dari 24 domain aktif (default: zallpyx.xyz / rzmail.my.id)
pin 123456 (Opsional) Kunci custom email ini langsung dengan PIN keamanan
CONTOH REQUEST URL (PATH LANGSUNG):
https://rzmail.my.id/api/custom/botregister@zallpyx.xyz
ATAU MENGGUNAKAN QUERY PARAMETER:
https://rzmail.my.id/api/custom?name=botregister&domain=zallpyx.xyz
CONTOH RESPON JSON (201 CREATED): 
{
  "success": true,
  "address": "botregister@zallpyx.xyz",
  "isLocked": false,
  "isOwner": true,
  "created": true
}

🚀 Buka di Browser

GET /api/inboxes/:address/lock
🚀 Buka di Browser

Mengunci inbox dengan 6-digit PIN keamanan (SHA-256). Setelah dikunci, pesan masuk hanya bisa diakses dengan menyertakan parameter ?pin=123456.

CONTOH REQUEST URL:
https://rzmail.my.id/api/inboxes/user@zallpyx.xyz/lock?pin=123456
CONTOH RESPON JSON (200 OK): 
{
  "success": true,
  "message": "Inbox successfully locked with PIN"

BOT INTEGRATION

Contoh Integrasi Bot (1 Baris HTTP GET)

PYTHON BOT SCRIPT: 
import requests, time

# 1. Buat custom email atau email acak instan via GET
mail_res = requests.get("https://rzmail.my.id/api/custom/mybot@zallpyx.xyz").json()
email = mail_res["address"]
print(f"[*] Email dibuat: {email}")

# 2. Tunggu OTP (contoh Canva) masuk via endpoint /api/otp
print("[*] Menunggu kode OTP...")
for _ in range(30):
    time.sleep(2)
    otp_data = requests.get(f"https://rzmail.my.id/api/otp/{email}").json()
    if otp_data.get("has_otp"):
        print(f"[✓] KODE OTP MASUK: {otp_data['otp']}")
        print(f"[✓] Pengirim: {otp_data['from']} | Subject: {otp_data['subject']}")
        break
NODE.JS / TELEGRAM BOT: 
// 1. Buat custom email instan
const res = await fetch('https://rzmail.my.id/api/custom/mybot@zallpyx.xyz');

// 2. Cek OTP Canva secara instan
const otpRes = await fetch(`https://rzmail.my.id/api/otp/${address}`);
const otpData = await otpRes.json();
if (otpData.has_otp) {
  console.log('KODE OTP:', otpData.otp);
}
